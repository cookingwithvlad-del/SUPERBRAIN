# SUPERBRAIN

Chef Vlad's Claude system: how I think, the rules Claude follows on my work, which project ("station") each kind of work lives in, and the tools and skills each station uses.

| Folder | What's in it |
| --- | --- |
| `CLAUDE.md` | Loaded automatically by Claude Code in this repo: who I am and my house rules |
| `house-rules.md` | The rules every deliverable follows, and my reusable brief |
| `stations/` | One file per Claude project, with the instruction text to paste into it |
| `tools/` | Which connectors and plugins to keep, fix or remove |
| `.claude/skills/` | My personal skills: `vlad-brief`, `vlad-reel-producer`, `vlad-recipe-writer` |
| `plan/super-brain.html` | The full plan as a page |

## How to use it

1. Save the three skills in claude.ai (or use them straight from this repo in Claude Code).
2. Create one Claude project per file in `stations/` and paste its instruction block.
3. Turn on only that station's connectors.
4. When a rule changes, edit it here so every project picks it up.

> This repo is public. Keep client details, guest names, prices, investor numbers and anything private out of it.
